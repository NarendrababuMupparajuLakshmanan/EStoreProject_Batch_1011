What is HttpContext?
HttpContext is a Class which hold both request and response Object.
HttpContext will transfer data from web server to web client / web client to web server

HttpContext Class will be part of .Net Core WebApplication Class. 
While creating an object WebApplication, we can easily detects the Request and Response
object with the help of HttpContext Class.

What is Middleware and its Implementation?
====================================
Middle ware is a concept to implement a logic basic on data.
we are receiving data with the help of HttpContext Class.

To execute middleware, we will use Run() method.

app.Run() --> This method will be used for executing the Final Middleware also called as 
terminal Middleware. This Method will terminate the Middleware chain.

app.Use() --> This method will be used for executing the current Middleware and make a call
of subsequent middleware with the help of RequestDelegate Object
